Source: https://github.com/google/fonts/tree/main/ofl/manrope
Noto Sans SC — SIL Open Font License 1.1; derived self-hosted font renamed Radar Sans SC.
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
Radar Sans SC preserves GB2312 characters plus ASCII, Chinese/fullwidth punctuation; uncommon glyphs fall back to system fonts.
Both are WOFF variable fonts, font-display:swap. No system font installation and no runtime font CDN.
The two OFL files in this directory retain the original copyright notices and full licenses.
radar-emblem.webp and reset-card-art.webp are AI-generated decorative UI artwork; live numbers and progress remain text/SVG.
