# 图标设计与接入

推荐方向：01 precision / 精密蓝。

语义：同心双环表达雷达，右上扫描扇形表达检测，中心亮点形成视觉锚点。不引入文案、重置卡细节或复杂网格，避免小尺寸拥挤。

母稿画布 512px。圆角底板从 (24,24) 到 (488,488)，半径 108px；中心 (256,256)，外环半径 172px、内环 104px。底板距画布边缘 24px，外环距画布边缘 76.5px，保障常规裁切时主体安全。

配色：底板 #071B38 / #102F57，主环 #46E4F4，次环 #179BF1。16–24px 增粗外环并移除内环，保留扇形、扫描边线和中心亮点。32px 以上使用完整双环版本。正式稿不使用外部光晕，降低边缘模糊。

## Tauri 接入建议

1. 在原工程中备份旧图标，将本包 `icons/reset-radar.ico` 复制到项目图标目录。
2. 在工程的 Tauri 配置中设置 Windows 图标路径，保留其他平台必要的图标配置；具体配置格式按项目 Tauri 版本确认。
3. 如果运行窗口有独立图标设置，也需同步资源。重新构建后检查 exe、窗口标题栏、任务栏及安装包图标。
4. 界面内 logo 可使用 `reset-radar-mark.svg`；在需要深色标记的浅色环境中使用 02 glass 的 SVG 配色，不要将亮色透明标记直接放在白底上。
5. 验证 Windows 100%、125%、150%、200% 缩放；系统缓存可能导致旧快捷方式图标延迟更新。

本轮验证文件本身的尺寸、透明通道和 ICO 帧结构；应用内接入需在原工程中完成。
