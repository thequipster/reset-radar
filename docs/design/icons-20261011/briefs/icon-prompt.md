# 应用图标提示词（RR27 后新增建议）

为 Windows 桌面悬浮工具 reset-radar 生成应用图标（将来用作 exe 图标/任务栏/关于页）。

要求（只约束内容语义，风格配色交给生图 AI 自由探索）：
- 主体：一枚"雷达/声呐扫描"意象——同心圆环 + 中心亮点 + 一道扫描扇形；可融入"额度环（进度环）"或"重置卡"次级元素，但主体必须一眼是雷达。
- 用途与形状：方形画布，主体居中，四角留安全边距（缩小到 32px 仍可辨识；Windows 任务栏为圆角方形裁切）。
- 气质：安静、精密、常驻工具感；避免拟物杂讯与高复杂度细节。
- 输出建议：先出 4–6 个候选方向（扁平线性 / 玻璃拟态 / 渐变霓虹 / 单色印章等），选中后再细化正稿。
- 现有界面里的手绘 SVG 版雷达 logo（src/ui/icons.tsx RadarLogo：同心双环+扫描扇形+信号点）可作语义参照（见包内参考图）。
