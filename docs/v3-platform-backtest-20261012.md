# v3 平台模型理想化回测（2026-10-12）

本报告用现有归档夹具评估平台公告目标 P。结果是按公告时间可获得性的**理想化时间顺序回测**，不是历史在线预测成绩，也不据此升级 P1。

## 数据与覆盖

- 夹具：`data/resets-history.json`，采集时间 `2026-10-11T13:41:25.735Z`；来源/API schema 见 `TRUTH.md` §1 B07。
- 分页契约核对了公开 [OpenAPI 文档](https://codex-resets.com/api/openapi.json)：`GET /api/v1/resets` 的 `cursor` 是上一页返回的 opaque cursor。2026-10-12 实测当前首屏返回 60 条、`has_more=false`、`next_cursor=null`；跨页路径由 `scripts/fetch-history.test.mjs` mock 验证。
- 夹具有 60 条事件，筛出 54 条 `regular`。分页元数据为 `has_more=false`、`next_cursor=null`，代表采集时已到完整末页。覆盖从最早 regular `2025-09-17T04:02:52.000Z` 到抓取截点，按 complete coverage 计算；截点之后没有计入暴露。
- 54 条 regular 形成 53 个相邻完整间隔。夹具没有历史 `firstSeenAt`，回测只能假设每条公告在 `announcedAt` 即可见；所以回测标记 `idealized=true`。
- 训练口径：所有有效间隔终点计 K，截点尾段只计删失暴露 E。年龄段为 `[0,3)、[3,9)、[9,+∞)` 天，P1 收缩常数 28 天。正式输出 P0 常数率，P1 仅作影子比较。

## 固定时点时间顺序回测

在数据区间内按每天北京时间 09:00 发行 24 小时预测；每个截点只训练当时已公告事件，结果标签从全量实际公告及完整覆盖区间生成。共生成 388 个发行时点，其中 P0/P1 均可评分的 339 个，正例 51 个。

| 模型 | Brier 分数 |
|---|---:|
| P0 常数率 | 0.131223 |
| P1 年龄分段影子 | 0.130451 |
| 差值（P0 − P1） | +0.000772 |

按完整周分块后有 49 个周块，其中 22 个周块 P1 的 Brier 更低，27 个周块更高。另按整周有放回重采样 1,024 次（固定 seed `20261012`），P0−P1 Brier 改善估计为 `0.0007724`，2.5%–97.5% 分位区间为 `[-0.0008433, 0.0026344]`，包含 0；因此 `weeklyBlockRobustness=unclear`。该区间是描述性周块 bootstrap，保留周内连续日预测的相关性，不把重叠窗口当成独立样本，也不代表在线验证。

## 结论与边界

本样本中 P1 整体 Brier 略低，但周块 bootstrap 改善区间包含 0，且改善只出现在 22/49 周块。没有 first-seen 记录也无法还原当时实际可见的数据或确认预测曾被发行。因此结果保留为理想化历史参照，`upgradeEligible=false`，P0 继续正式使用、P1 继续影子运行。

数值由 `src/lib/v3/platform.ts` 的 `fitPlatformModel`、`predictPlatform`、`backtestPlatform` 对归档夹具直接计算；报告生成过程没有改写夹具。
