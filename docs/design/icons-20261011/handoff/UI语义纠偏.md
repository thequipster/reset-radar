# UI 参考交接与语义纠偏

原图只用于视觉方向与层级参考，准确语义以 `prompts.md` 为准。

| 区域 | 实施要求 |
| --- | --- |
| 剩余额度 | 周额度 29%、短窗 64%，标签分开。 |
| 今日行动 | 明确写「今日建议追加 8.7 个周额度百分点」；执行后周余可在该演示中显示 20.3%。 |
| 建议解释 | 均匀配速、风险前拉、软上限、最终建议四项。原图把软上限写成 -1.2 pct 并暗示相加，应纠正为限制条件。没有业务公式时不伪造推导。 |
| 风险 | 25.4% 必须标为未来 24h 强制重置模型风险；58.0% 标为 48h 碰撞估计。因子展示正负号、百分点单位与说明入口。 |
| 公告 | 完整计划时刻、北京时间、来源、获取时间，并写「尚未确认发生」。计划不是已发生事件。 |
| 用卡规划 | 明确「等待最佳用卡日」。期望收益是预计额外消耗的周额度百分点，候选日期图不是消耗历史。日期与星期应从同一数据生成。 |
| 首次加载 | 保留布局、显示「读取中」，无假读数或假进度。 |
| 空数据 | 「— / 暂无额度数据」，提供刷新入口。 |
| 首次失败 | 数字仍为占位，失败原因与重试入口清楚可见。 |
| 过期数据 | 保留可信旧值，标「数据过期 / 上次观测时间」，旧建议注明依据上次观测。 |
| 零卡 | 「卡 ×0 / 无可用重置卡」，其他数据正常展示。 |
| 未知卡数 | 「卡 — / 卡数未知」，不输出确定无卡决策或确定用卡收益。 |
| 校准 | 零计分样本写「数据积累中」。 |

## 交互验收

展开面板：退出、收起始终可达，细节区域可滚动，说明可展开。

悬浮条：拖动区与展开按钮分开；周余、风险、卡数、采集状态均有独立标签。

预览层：悬停与键盘聚焦均可触发，鼠标能移入预览；进入完整规划后保持展开。

双主题：内容顺序、数值单位与可用操作一致。异常既有文字也有视觉标记。

这些是设计交接条目，并非对未提供原工程的功能测试结果。
