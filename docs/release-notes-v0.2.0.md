# reset-radar v0.2.0

正式版更新：

- 修复悬浮球四边半圆方向、松手吸附，以及底部展开面板超出工作区的问题。
- 调整交互为「悬浮球 → 额度条 → 完整面板」，额度条整体可点开。
- 改善额度采集握手、超时与刷新状态；失败和缺失数据会如实显示。
- 主题简化为浅色、深色；提升额度数字对比度，统一风险颜色，补齐规划图空态。
- 接入 v2 风险、配速和用卡模型；新增按账户隔离的日耗观测与决策日志，样本不足时明确提示依据不足。

Windows x64：下载 `-setup.exe` 安装包，或使用 `.msi`。`SHA256SUMS.txt` 提供文件校验值。

验收：342 条前端测试、38 条脚本测试、41 条 Rust 测试通过；三处变异红验通过，原生四边窗口定位与双主题十张截图复核通过。自动化拖拽使用 DOM 事件；多显示器混合 DPI 仍需实机确认。
