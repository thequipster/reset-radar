报告16项由 trend.v31.test（权重、积分、可靠尾段/空档、未来、banked、条件化起点、换算、回放与启用）、coldStart.v31.test（40/96/12=5、零历史动作、耗尽等待、临期/翻转动作、满额闲置）、policy-default.v31.test（无需求跑三档/集中、选择翻转、无收益不空打）、verdict.v31.test（成熟计分、迟到纠正、缺覆盖unknown、临时组分离、周配对阈值）与既有双窗/用卡7天/取消旧自然事件测试共同覆盖。

UI组件新字段输出 expectedConsumption / allocationBudget / coldAdvice，worker运行前即有明确保守主动作和默认预算，worker完成再补成对模拟条件结果。未手填截止的服务端卡仍仅未知占位；不自动使用真实卡。

## 使用

node scripts/v31-report.mjs [可选本机cards日志路径] 输出同截点回放与verdict汇总，不写生产日志。临时编译模块位于OS临时目录；输入仍为纯TS唯一实现，不是第二份算法。

本轮不push、不变更已经发布v0.2.0资产。需要后续真实观测的是模型成熟证据，并非功能启用前置。没有需用户先补数据的阻塞项。
