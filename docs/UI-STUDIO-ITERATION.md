# Reset Radar · 工作台视觉迭代

本次以两轮「一句话生图 → 落地前端 → 截图复核」完成。

## 第一轮
提示：为 Reset Radar 设计一张精美且富有创造力的中文桌面应用界面：它帮助 Codex 用户查看剩余额度、更新重置公告、判断风险窗口，并先推荐用卡时间再安排用量。
落地：青绿深色、左侧导航、配套浅色主题、额度卡片、概率雷达、双列工作台。雷达只展示真实的24小时平台公告参考概率；没有虚构风险维度或安全承诺。

## 第二轮
把真实截图交给生图模型，以一句话请求更精致、舒展且首屏重点更突出的工作台。
落地：用卡建议提升为主卡片，增加启用风险优先规划入口；公告来源信息折叠；已知日程改成时间线。
未采用概念图虚构的「今晚最佳窗口」和未经模型支持的每日风险级别。

## 窗口与兼容
- 展开：1080×800，由现有窗口逻辑按显示器工作区夹紧。
- 迷你圆、悬浮条、预览尺寸保持不变。
- 620px以下切换顶部导航和单列布局；日历横向滚动，标签保持整词。
- 配色限于展开工作台，不改全局主题契约及迷你浮窗。

## 复现验证
1. `node node_modules/typescript/bin/tsc --noEmit`
2. `node node_modules/vitest/vitest.mjs run`
3. `node node_modules/vite/bin/vite.js build`
4. `node scripts/qa-studio-ui.mjs`

浏览器测试使用本机已有Edge的headless模式及独立演示profile，不接管用户浏览器、不读取实际账号；覆盖1080、460、360宽度及深浅主题，截图与报告位于 `release-qa/studio-ui/`。
本次不打包发布桌面exe、不推送远端。
