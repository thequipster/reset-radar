# 参考图交接

按 `../03-image-prompts.md` 生成并选定参考图后，将图片放在本目录。

建议先生成展开态并选中视觉方向，再以它为参考补齐其他图。推荐命名：

- `01-expanded.png`：展开态全貌
- `02-compact.png`：悬浮条
- `03-peek.png`：迷你预览
- `04-components.png`：组件与解释
- `05-states.png`：全状态
- `06-themes.png`：深浅主题

目前没有参考图片，只有本交接说明；未开始阶段4实施。使用其它文件名亦可。选中的展开态与悬浮条至少应到位；其余图可减少还原歧义。若使用其它来源的参考素材，附来源说明便于完成报告注明出处。
