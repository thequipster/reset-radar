## 定夺

**RR35（2026-10-11）**：尾箭头 token 化 `--banner-tail`（rgba 白 0.65→0.9）+ 22px/700——
本表口径半透明前景按字面 rgb 亮度近似（alpha 不入亮度），数值 5.38 不变；本轮属
REVIEW 第3轮 G1① 视觉权重（尺寸）差距修复，非对比度数值修复。达标数深 38/浅 31 不变。

**RR34（2026-10-11）修复后基准**：深色 38/42 达标（原 33）、浅色 31/42 达标（原 20）——
达标数只升。本轮修复面（横幅系+顺带轻缺陷，两主题全达标）：

- 横幅渐变：深色 a 段 #a855f7→#9333ea（白字 3.96→5.38）；浅色整体由浅紫渐变
  #ede4ff/#e6dcff/#e0e7ff 换深紫渐变 #9333ea/#7c3aed/#4c1d95（与深色统一，紫语义保持），
  白字 1.23–1.51 → 5.38/5.70/10.95。
- 副文案 token 化 --banner-sub #f3e8ff（深 2.14/3.09 → 4.56/4.83；浅 1.51/1.41 → 同值）。
- 浅色大数字 #7c3aed→#ffffff（4.35–4.65 → 5.38–10.95，与深色统一白）。
- 顺带：decision-icon token 化（浅 #854d0e=5.81，深 #facc15=6.15 保持）；浅色 --warn
  #d97706→#b45309（状态点 2.99→4.71，与 --warn-text 同值语义）。

余留不达标（RR29 定夺沿袭，均为设计取舍留档，不立修卡）：

- 深色 4 组：tertiary 系三组（3.24–3.64，三级辅助文本，视觉层级意图）+ white-on-accent-blue
  （3.94，实底按钮白字贴线，按钮有边框+尺寸冗余）。
- 浅色 11 组：tertiary 系三组（2.82–3.00）+ blue-bright 系五组（3.27–3.68，浅色下亮蓝
  链接/图标的设计取舍）+ cyan-on-card（3.68）+ success-on-card/success-dim（3.30/2.95）
  + danger-text-on-danger-dim（3.95）。语义色列（蓝/青/绿）在浅色底换深会破坏与深色主题
  的色彩语言对仗，留整体设计定夺（用户可在线时点单）。
